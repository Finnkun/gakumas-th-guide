รีโรลอย่างไร และควรหยุดเมื่อไร

รอบแรกใช้เวลาประมาณ 10 นาที ส่วนรอบถัดไปสั้นลงมากเพราะข้าม Tutorial ได้ เป้าหมายที่สมเหตุผลคือของระดับสูง 2 ชิ้นที่ใช้ร่วมกันได้

เส้นชัยของการรีโรล

SSR ระดับสูงสองชิ้นถือว่าดีมาก จะเป็น P Idol สองตัว หรือ P Idol หนึ่งตัวร่วมกับ Support Card หนึ่งใบก็ได้ เนื่องจากเลือก SSR เริ่มต้นจากรายชื่อที่กำหนดได้ จึงควรใช้รีโรลกับของที่หาแทนยากกว่า

อันดับเปลี่ยนตามตู้
ตรวจวันที่ก่อนใช้เวลา เพชร หรือตั๋วทุกครั้ง

ขั้นตอนย่อ

  1. ข้ามวิดีโอ ตั้งชื่อ และเล่น Tutorial รอบแรก
  2. ข้าม Live หลังสอบ เลือก Memory Photo และดาวน์โหลดข้อมูล
  3. รับตั๋วกับเพชรจากกล่อง แล้วเปิดกาชา
  4. ถ้าไม่พอใจ: Title → เมนูสามขีด → ลบ User Data
  5. ยอมรับเงื่อนไขและข้าม Tutorial เพื่อเริ่มรอบใหม่
