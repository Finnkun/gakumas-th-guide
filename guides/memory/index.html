Memory: คีย์สกิลก่อน สีและตัวเลขทีหลัง

Memory ที่ดีช่วยลดความสุ่มตั้งแต่เริ่มรอบ โดยใส่สกิลจำเป็นเข้าเด็คและเสริมเปอร์เซ็นต์ค่าสถานะที่ตรงกับแผน

ลำดับการประเมิน

  1. สกิลตรง Plan และเป็นคีย์สกิลหรือไม่
  2. เป็นสถานะเริ่มได้รับทันทีหรือเพิ่มเข้าเด็คภายหลัง
  3. โบนัส % ตรงค่าสถานะหลักหรือไม่
  4. เด็คเริ่มต้นหนาเกินไปหรือไม่

ลดความสุ่มในการสร้าง

หลักคือทำให้จำนวนการ์ดที่มีโอกาสถูกเลือกเป็น Memory เหลือน้อยที่สุด ใช้ Memory ยืมที่มีสกิลเป้าหมาย หลีกเลี่ยงรับการ์ดอื่น และอย่าใช้เอฟเฟกต์เปลี่ยน Basic Card หากจะทำให้ตัวเลือกปน

เป้าค่าสถานะ
การจบรอบด้วยค่าสูงช่วยให้มีโอกาสได้โบนัสที่ดีขึ้น แต่ไม่ควรสละคีย์สกิลที่จำเป็นเพียงเพื่อไล่ตัวเลขสวย
