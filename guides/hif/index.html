H.I.F: สิ่งที่ต้องรู้ก่อนเริ่มปั้น

H.I.F สืบโครงสร้างหลายอย่างจาก N.I.A แต่เพิ่มเพดานค่าสถานะเป็น 3,000 และให้ปรับแต่ง P Item หลังผ่านการสอบแต่ละครั้ง

ต่างจาก Scenario เดิม

  • รูปแบบใกล้เคียง N.I.A และมีการสอบคัดเลือก 3 ครั้ง
  • เพดาน Vo / Da / Vi เพิ่มเป็น 3,000
  • มี Custom P Item ที่ปรับตามไอดอลและทีมได้
  • ไม่มี Challenge P Item และ Legend Card แบบทั่วไป ยกเว้นเงื่อนไข STEP 3

การเดินตาราง

สลับ Lesson, 授業, お出かけ และ 相談 ตามทรัพยากร ตัวเลือกบนสุดของ お出かけ ใช้ 50 P Point แลกสกิลการ์ด 2 ใบ จึงช่วยสร้างเด็คได้ดี

แกนการวางแผน
เลือกโบนัสและ Custom P Item ให้เสริม 好調 / 集中 / 好印象 / やる気 / 強気 / 全力 ของตัวที่เล่น

ก่อนเริ่มรอบ

  1. ตรวจเงื่อนไขชนะของไอดอล
  2. นำ Memory ที่ป้องกันคีย์การ์ดขาด
  3. จัด Support รองรับค่าสถานะและกิจกรรมที่เกิดบ่อย
  4. วางแผน P Point สำหรับ お出かけ, 相談 และ Custom P Item
