เส้นทางมือใหม่: จากวันแรกถึง True End

เป้าหมายช่วงแรกไม่ใช่การปั้นตัวเดียวให้สุด แต่คือการเรียนระบบ เพิ่ม PLv และสร้างฐานตัวละครอย่างน้อย 3 คนสำหรับ Contest

ลำดับที่แนะนำ

  1. รีโรลหา SSR ที่ช่วยบัญชีระยะยาว โดยการ์ดซัพพอร์ต SSR อย่างน้อย 2 ใบเป็นจุดเริ่มต้นที่ดี
  2. เลือก SSR P Idol เริ่มต้นเป็นตัวที่ชอบ แล้วเล่น Produce ให้จบหนึ่งรอบ
  3. เข้า 研修 เพื่อเรียนระบบสำคัญ
  4. เร่งทำ 初星課題 เพราะเป็นทางหลักในการเพิ่ม PLv และปลดล็อกฟังก์ชัน
  5. ทำภารกิจผู้เล่นใหม่ควบคู่กัน แล้วค่อยลงทุนอัปเกรดตัวที่ใช้งานจริง
  6. ปั้นอย่างน้อย 3 ไอดอลสำหรับ Contest ก่อนพยายามทำ True End
เป้าหมายอัปเกรดช่วงต้น
P Idol: 特訓 ระดับ 3 · Support Card: ระดับ 25

จัดซัพพอร์ตและ Memory

ดูค่าสถานะหลักแล้วจัดซัพพอร์ตแบบ 3:3:0 หรือ 3:2:1 เน้นสองค่าที่สำคัญ การ์ดเพิ่มโอกาส SP Lesson และโบนัสค่าสถานะมักมีมูลค่าสูง ส่วน Memory ช่วยนำคีย์สกิลเข้าสู่เด็คอย่างแน่นอน

รักษาพลังงาน

  • พักหรือออกไปข้างนอกเมื่อพลังงานไม่พอผ่าน Lesson
  • จบ Lesson ก่อนหมดเทิร์นเพื่อรับพลังงานคืนเล็กน้อย
  • 元気 รับค่าพลังงานสีเขียวแทนได้ แต่รับค่าหัวใจสีแดงไม่ได้
  • P Drink ใช้แล้วไม่เสียเทิร์นและถือได้จำกัด อย่าเก็บจนเต็ม
