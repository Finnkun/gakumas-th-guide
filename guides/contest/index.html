Contest: ทีมที่ดีเริ่มจากอ่านกติกา

Contest ใช้ผลการปั้นที่บันทึกใน Memory และเปลี่ยนเงื่อนไขตามฤดูกาล จึงไม่มีทีมเดียวที่ดีที่สุดตลอดไป

ก่อนจัดทีม

  1. อ่าน Stage Effect และ Plan ที่อนุญาต
  2. เลือก P Idol ที่กลไกเข้ากับจำนวนเทิร์น
  3. ใช้ Memory ที่มีเด็คเริ่มต้นและคีย์สกิลเหมาะกับ Auto
  4. ตรวจพลังรวมและกระจายทรัพยากรให้ครบทุกตำแหน่ง
Auto ต่างจากเล่นเอง
เด็คที่ซับซ้อนหรือมีการ์ดผิดจังหวะอาจทำงานแย่ ควรลดการ์ดที่แย่งลำดับจากคีย์สกิล
